# Awesome Design Skill

This skill provides a repository of modern design patterns to create visually stunning applications.

## Modern Trends

1.  **Bento Grids**: Use dense, card-based layouts (like Apple's widget screens) to display varied content. Use CSS Grid for precise placement.
2.  **Glassmorphism**: Combine semi-transparent backgrounds with background-blur (`backdrop-filter: blur(10px)`) and subtle white borders to create frosted glass effects.
3.  **Neo-Brutalism**: (Use selectively). High contrast, bold typography, stark black borders, and solid primary colors to create a raw, unpolished look.
4.  **Dark Mode Excellence**: True black (`#000000`) is often too harsh. Use deep grays or tinted dark colors (e.g., `#0f172a`) for backgrounds, and adjust accent colors to be less saturated in dark mode to prevent eye strain.
5.  **Gradients**: Use mesh gradients or subtle linear gradients as backgrounds. Avoid harsh stops; blur gradients for a softer, organic feel.
