# Web Design Guidelines

This skill provides a mathematical and systematic approach to beautiful web design.

## Core Rules

1.  **60-30-10 Color Rule**: 60% of the UI should be a dominant (usually neutral) background color, 30% a secondary (surface) color, and 10% an accent color for CTAs.
2.  **Modular Scale**: Use a consistent mathematical ratio (e.g., 1.250 Major Third) to determine font sizes (`h1`, `h2`, `p`, `small`) rather than picking arbitrary pixel values.
3.  **Fluid Typography**: Use CSS `clamp()` to create typography that scales smoothly between mobile and desktop breakpoints without needing media queries for every size.
4.  **Vertical Rhythm**: Maintain consistent vertical spacing between elements using a base unit (e.g., 8px). Margins and paddings should be multiples of this base unit.
5.  **Contrast & Accessibility**: Ensure text contrast meets WCAG AA standards (4.5:1 for normal text).
