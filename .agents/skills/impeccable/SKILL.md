# Impeccable Skill

Apply this skill to write code that is absolutely robust and error-free.

## Core Directives

1.  **Zero-Defect Mindset**: Anticipate every possible edge case, null reference, and boundary condition. Add guards and fallbacks.
2.  **Rigorous Testing**: Assume the code is broken until proven otherwise. Write testable code, inject dependencies, and ensure high coverage.
3.  **Perfect Syntax**: Follow language conventions strictly. Use linters, formatters, and type checkers. No "any" types in TypeScript, no suppressed warnings.
4.  **Robust Error Handling**: Never swallow errors silently. Catch, log, and gracefully degrade or report errors to the user in a helpful manner.
