# Taste Skill

This skill elevates the visual quality of a project from "functional" to "beautiful".

## Design Principles

1.  **Whitespace is Content**: Use generous, intentional whitespace to let elements breathe. Group related elements using proximity.
2.  **Color Theory**: Avoid harsh, fully saturated primary colors. Use carefully chosen palettes, subtle gradients, and ensure accessible contrast ratios.
3.  **Typography Mastery**: Select highly legible, modern fonts (e.g., Inter, SF Pro, Geist). Establish a clear typographic hierarchy with distinct font sizes and weights.
4.  **Visual Hierarchy**: Guide the user's eye naturally. The most important element on the screen should be immediately obvious through size, color, or placement.
5.  **Restraint**: Don't overdesign. Sometimes the best design is the one that is almost invisible, relying on structure rather than heavy styling.
