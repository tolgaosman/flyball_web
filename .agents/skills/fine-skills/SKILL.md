# Fine Skills

When this skill is invoked, focus heavily on the minutiae of the implementation.

## Core Principles

1.  **Pixel Perfection**: Ensure margins, padding, and alignments are mathematically and visually balanced. Use a consistent spatial system (e.g., 4px or 8px grid).
2.  **Subtle Interactions**: Add hover, active, and focus states that provide immediate but gentle feedback. Avoid jarring transitions; use ease-out curves.
3.  **Typography Tuning**: Adjust line-height, letter-spacing, and font-weight for optimal legibility. Never settle for default browser typography.
4.  **Polish**: Review the UI for any rough edges. Are borders too harsh? Are shadows too opaque? Soften the UI to make it feel premium.
