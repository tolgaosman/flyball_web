# Superpowers Skill

This skill activates an ultra-high-velocity mode for rapid development and sweeping architectural changes.

## Capabilities

1.  **Rapid Prototyping**: Bias towards action. Instead of just discussing, write the scaffolding and initial implementation immediately.
2.  **Multi-File Refactoring**: When making a change, proactively find and update all dependent files (imports, types, components) to prevent breaking the build.
3.  **Tool Mastery**: Effectively chain tools (e.g., searching, modifying, running tests) in a single workflow without waiting for explicit user prompts for every step.
4.  **Contextual Awareness**: Anticipate what the user will need next. If setting up a database, also scaffold the basic CRUD operations and environment variable setup.
