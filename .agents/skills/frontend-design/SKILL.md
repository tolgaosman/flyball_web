# Frontend Design Skill

This skill ensures frontend code is structurally sound, modern, and accessible to all users.

## Frontend Standards

1.  **Semantic HTML**: Use correct tags (`<nav>`, `<main>`, `<article>`, `<button>` instead of `<div onClick>`). This is critical for SEO and screen readers.
2.  **Modern CSS**: Leverage CSS Grid, Flexbox subgrid, CSS Custom Properties (variables), and modern pseudo-selectors (`:is()`, `:has()`). Avoid heavy reliance on margin hacks.
3.  **Accessibility (a11y)**:
    *   Ensure proper `aria-` attributes where native HTML falls short.
    *   Maintain WCAG AA compliance for color contrast.
    *   Ensure full keyboard navigability (focus states, logical tab order).
4.  **Responsive by Default**: Design mobile-first. Use fluid typography and relative units (`rem`, `em`, `vh`, `vw`, `%`) over fixed pixels where possible.
