# UI/UX Pro Max Skill

This skill focuses on the psychological and scientific principles of user interface design.

## UX Laws in Practice

1.  **Fitts's Law**: Make important interactive elements (like primary CTAs) larger and place them closer to the user's natural cursor/finger position.
2.  **Hick's Law**: Reduce cognitive load by limiting choices. Break complex forms into multi-step wizards. Hide advanced settings behind "More options".
3.  **Jakob's Law**: Users spend most of their time on *other* sites. Use familiar UI patterns (e.g., gear icon for settings, magnifying glass for search) rather than reinventing the wheel.
4.  **Feedback Loops**: Provide immediate visual/auditory feedback for every action (loading spinners, success toasts, subtle button press animations).
5.  **Error Prevention**: Design interfaces that prevent errors before they happen (e.g., disabling the submit button until the form is valid, clear inline validation).
